# modules

Index of modules ported to run natively against the MySU JS bridge (`window.mysu`), maintained by [kelexine](https://github.com/kelexine).

This is a personal module index, not a general submission repository -- modules are added here as they get ported for personal use.

## Format

`modules.json` is a flat array of module manifests:

```json
{
  "id": "example-module",
  "name": "Example Module",
  "version": "1.0.0",
  "versionCode": 1,
  "author": "someone",
  "description": "What it does.",
  "downloadUrl": "https://example.com/example-module.zip"
}
```
